# WearWise — iPad Home Screen Icon Update (Version 5)

This version keeps the Version 4 weather and clothing illustrations, and adds the custom WearWise app icon.

## Update your existing GitHub Pages site

1. Unzip `wearwise-v5-github-pages.zip`.
2. Open your existing WearWise repository on GitHub (the repository containing your live `index.html`).
3. Upload **all three files** from this folder to the **same directory** as the existing `index.html`: `index.html`, `apple-touch-icon.png`, `wearwise-icon.png`.
4. Commit the changes and wait for GitHub Pages to publish.
5. On your iPad, remove only the existing WearWise Home Screen bookmark (not the files on GitHub).
6. Open the WearWise website in Safari, tap Share → Add to Home Screen, and add it again. The new icon should appear.

The original forecast, location options, and detailed clothing recommendations are unchanged.
